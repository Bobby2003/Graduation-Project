认证与密码

使用 Django 内置认证；密码经单向哈希存储，系统不保存明文。建议开启密码复杂度校验（本项目 settings 已配置常用校验器）。

会话与 CSRF

登录会话使用 HttpOnly Cookie；表单提交使用 CSRF Token。生产部署在 HTTPS 下建议启用 SESSION_COOKIE_SECURE 与 CSRF_COOKIE_SECURE。

输入与注入

业务逻辑使用 Django ORM，避免手写拼接 SQL。模板默认转义输出，请勿对不可信内容使用 |safe。

WebSocket

实时通道在服务端以会话用户为准，不信任客户端伪造的用户 ID 或资产数值；消息应限频与校验格式。

关键操作

经验、货币、成就解锁、购买与任务完成等须由服务端校验与持久化，不可仅依赖前端脚本。
