核心模块

系统由多个高度解耦的模块协同工作

🧭

IMU 位姿估计

9 轴 IMU 四元数解算旋转矩阵，加速度积分提供位移初值，高通滤波抑制漂移，静止检测自动归零速度。

CH340 串口
🔗

ICP 点云配准

以 IMU 增量变换为初始值，Point-to-Plane ICP 精确修正帧间位姿，fitness > 0.3 时接受并反向校正漂移。

Open3D Tensor
⚡

GPU 加速渲染

自动检测 CUDA 设备，点云张量运算全程在 GPU 执行，每 4 帧体素降采样，保持全局地图轻量高效。

CUDA / Open3D
🗺️

全局地图构建

配准帧累积融合进全局点云，定期体素降采样去冗余，退出时统计滤波去噪并导出 PLY 格式文件。

PLY 导出
🎨

RGB-D 融合

深度帧与 RGB 摄像头同步采集，颜色信息绑定到对应三维点，构建带真实纹理的彩色点云地图。

OpenCV
🔄

实时可视化

Open3D Visualizer 实时渲染点云，OpenCV 同步显示深度预览与 IMU 姿态数据，双窗口并行输出。

实时 60fps

握拳 → 张掌：打开菜单

任意一只手先握拳，3 秒内展开手掌，全息菜单弹出。同一只手再次握拳关闭菜单。

is_fist() → is_open_palm()
👆

食指指尖：移动光标

另一只手食指关键点 #8 实时映射为屏幕光标坐标，悬停时高亮对应按钮。

landmark[8].x/y → cursor
🤌

双击捏合：确认选择

拇指与食指距离小于掌宽 25% 判定为捏合，0.6 秒内两次触发即为双击选中。

dist(4,8) < palm×0.25 ×2
🔙

双击 BACK：返回主菜单

进入子页面后，光标悬停顶部居中 BACK 按钮并双击捏合，返回主菜单列表。

hit_test(cursor, back_btn)
