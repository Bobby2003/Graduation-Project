1. 直接运行默认正式版
python .\mesh_refine_pipelineGPU.py
作用：使用代码内默认配置直接运行。
默认等价于：

使用默认 PLY 输入
使用 balanced 预设
开启 CUDA
开启距离策略
使用默认输出目录
2. 运行正式平衡版
python .\mesh_refine_pipelineGPU.py --preset balanced
作用：使用推荐的正式平衡参数运行。
特点：质量与速度较均衡，适合作为默认正式输出。

3. 运行快速版
python .\mesh_refine_pipelineGPU.py --preset fast
作用：使用快速版参数运行。
特点：速度更快，适合批处理、预览、快速测试。

4. 运行细节版
python .\mesh_refine_pipelineGPU.py --preset detail
作用：使用细节保留版参数运行。
特点：保留更多 plane，适合更重视细节效果的情况。

5. 指定输入文件运行
python .\mesh_refine_pipelineGPU.py --input ".\input\your_mesh.ply"
作用：使用指定输入网格文件运行。

6. 指定输出目录运行
python .\mesh_refine_pipelineGPU.py --output_dir ".\outputs_test"
作用：将输出结果保存到指定目录。

7. 指定输入文件 + 平衡版运行
python .\mesh_refine_pipelineGPU.py --input ".\input\your_mesh.ply" --preset balanced
作用：对指定模型使用平衡版参数运行。

8. 指定输入文件 + 快速版运行
python .\mesh_refine_pipelineGPU.py --input ".\input\your_mesh.ply" --preset fast
作用：对指定模型使用快速版参数运行。

9. 指定输入文件 + 细节版运行
python .\mesh_refine_pipelineGPU.py --input ".\input\your_mesh.ply" --preset detail
作用：对指定模型使用细节版参数运行。
