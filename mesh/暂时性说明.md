目前就用slim这一版
主程序mesh_refine_slim.py
接入mesh_refine_adapter_slim.py
输出工作流数据mesh_refine_api.py
打印报告和参数config_slim.py
| 功能 | 调用 |
|---|---|
| 创建 pipeline | `pipe = MeshRefinePipeline(preset="balanced")` |
| 一行式入口（不建实例） | `refine_mesh("in.ply")` |
| 处理 mesh，仅返回 trimesh | `pipe.process(mesh_input)` |
| 处理 mesh，返回完整数据 | `pipe.process(mesh_input, return_details=True)` |
| 处理 + 保存到目录 | `pipe.process_and_save(mesh_input, "out_dir/")` |
| 处理 + 保存 + 输出 JSON | `pipe.process_and_save(mesh_input, "out/", export_json=True)` |
| 保存中间各阶段 mesh | `pipe.process(mesh_input, return_details=True, save_intermediate=True)` |
| 临时覆盖参数（不污染默认） | `pipe.process(mesh_input, verbose=False, num_workers=4)` |
| 永久更新配置 | `pipe.update_config(num_workers=8)` |
| 查看当前配置 | `pipe.get_config()` |
| 输入归一化（任意类型→trimesh） | `to_trimesh(mesh_input)` |
| Open3D 兼容入口（旧版签名） | `refine_mesh_in_memory(o3d_mesh)` |
| Open3D 输入 + 拿全数据 | `refine_mesh_with_details(o3d_mesh)` |
| Open3D ↔ trimesh 转换 | `o3d_to_trimesh(m)` / `trimesh_to_o3d(m)` |

调用：`from mesh_refine_api import MeshRefinePipeline, refine_mesh`
Open3D 用户：`from mesh_refine_adapter_slim import refine_mesh_in_memory`

## 输入

`mesh_input` 可以是以下任意一种：
- 文件路径 `str`（如 `"input.ply"`）
- `trimesh.Trimesh`
- `open3d.geometry.TriangleMesh`
- `(vertices, faces)` 元组

---

## 返回值

| 调用方式 | 返回类型 |
|---|---|
| `pipe.process(x)` | `trimesh.Trimesh` |
| `pipe.process(x, return_details=True)` | `PipelineResult` |
| `refine_mesh_in_memory(x)` | `(open3d.TriangleMesh, meta_dict)` |
| `refine_mesh_with_details(x)` | `PipelineResult`（其 `.mesh` 为 trimesh） |

---

## PipelineResult 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `result.mesh` | `trimesh.Trimesh` | 优化后的 mesh |
| `result.before` / `result.after` | `dict` | 前/后状态 `{vertices, faces, bbox_extent}` |
| `result.timings` | `dict` | 各阶段耗时（秒） |
| `result.planes` | `list[dict]` | 平面（含 `face_ids/centroid/normal/sigma/area/...`） |
| `result.refine_reports` | `list[dict]` | 每个平面的精修报告 |
| `result.hole_stats` | `dict` | 空洞修补统计 |
| `result.intermediate_meshes` | `dict` 或 `None` | 各阶段中间 mesh |
| `result.config` | `dict` | 实际使用配置摘要 |

### 便利属性

| 属性 | 说明 |
|---|---|
| `result.num_planes` | 平面数 |
| `result.total_time` | 总耗时（秒） |
| `result.vertices` / `result.faces` | 最终顶点/面数 |

### 便利方法

| 方法 | 说明 |
|---|---|
| `result.summary()` | 简短摘要 dict |
| `result.planes_summary()` | 轻量平面列表（可 JSON 化） |
| `result.to_json_dict()` | 完整可序列化 dict（不含 mesh） |
| `result.save_mesh(path)` | 保存 mesh（`.ply` 自动用 binary） |
| `result.save_all(out_dir)` | 保存 mesh + JSON + 中间 mesh |

## timings 的 key

```
clean_mesh_1          # [1/7] 基础清理
early_hole_fill       # [2/7] 空洞修补 + 裂缝桥接
filter_components     # [3/7] 连通分量过滤
detect_planes         # [4/7] 平面识别
refine_planes         # [5/7] 平面精修
remove_floating_noise # [6/7] 去游离碎块
clean_mesh_final      # [7/7] 最终清理
total                 # 全程总耗时
```

## 常用参数（**overrides 透传）

| 参数 | 默认 | 说明 |
|---|---|---|
| `preset` | `"balanced"` | `fast` / `balanced` / `detail` |
| `verbose` | True | 是否打印日志 |
| `num_workers` | 0 | 0 = 自动（cpu_count - 1） |
| `sensor_origin` | `"0,0,0"` | 传感器位置字符串 `"x,y,z"` |
| `use_distance_strategy` | True/False | near/mid/far 自适应 |
| `expand_rings` | 1 | 平面外扩 ring 数 |
| `disable_early_hole_fill` | False | 关闭空洞修补 |
| `disable_gap_stitch` | False | 关闭裂缝桥接 |
| `max_hole_diameter` | 1.5 | 空洞最大直径 |
| `max_bridge_dist` | 0.30 | 桥接最大距离 |
| `min_plane_faces` | 40 | 最终平面最小面数 |
| `min_plane_area` | 0.0008 | 最终平面最小面积 |
| `vertex_inlier_dist` | 0.008 | 顶点 inlier 距离 |
| `vertex_outlier_dist` | 0.085 | 顶点 outlier 距离 |
| `base_snap_strength` | 1.0 | inlier 吸附强度 |
| `base_normal_smooth_iterations` | 22 | 平滑迭代基线 |
| `no_boundary_protect` | False | 关闭边界保护 |
| `boundary_scale` | 0.10 | 边界顶点权重缩放 |

> 完整参数清单见 `mesh_refine_slim.build_parser()` 或 `config_slim.py`。
> 传错参数名会打印 `⚠️  unknown args ignored: [...]` 但不会报错。

## 最小调用模板

```python
# 模板 1: 文件 → 文件
from mesh_refine_api import MeshRefinePipeline
pipe = MeshRefinePipeline(preset="balanced")
mesh = pipe.process("in.ply")
mesh.export("out.ply")

# 模板 2: Open3D 在线（推荐高频调用）
from mesh_refine_adapter_slim import refine_mesh_in_memory
refined_o3d, meta = refine_mesh_in_memory(o3d_mesh, save_files=False, verbose=False)

# 模板 3: 拿全数据 + 落盘
from mesh_refine_api import MeshRefinePipeline
pipe = MeshRefinePipeline()
r = pipe.process("in.ply", return_details=True)
print(r.num_planes, r.total_time, r.timings)
r.save_all("out_dir/")
```

## 注意事项

- 顶点数 < 50 会跳过整个 pipeline，原样返回。
- `MeshRefinePipeline` **非线程安全**，多线程并发要么每线程一个实例，要么加锁。
- 高频调用务必复用 `MeshRefinePipeline` 实例（`refine_mesh()` 每次新建，循环里别用）。
- `result.planes` 含 numpy 数组不可直接 `json.dumps`，用 `result.planes_summary()`。
- `save_intermediate=True` 会保留 4 份 mesh 副本，**生产环境不要开**。
