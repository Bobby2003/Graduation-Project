AR REALM

将现实房间重构为虚拟位面的 AR/VR 游戏平台 · 类绿洲网关 · 私人位面 · 材质协议

VERSION 1.0.0 // GRADUATION PROJECT
📡
PROJECT OVERVIEW
AR REALM 定位为「现实空间重构型」AR/VR 游戏平台原型：结合类《头号玩家》的统一虚拟入口与房间副本 / 空间皮肤思路。 玩家通过桌面（预制室内 + WASD）、AR 手势或 VR 链路接入同一绿洲世界；以「材质协议 / 现实覆写」将真实或模板空间游戏化，并配套任务、装备、成就与私人位面存档。 深度扫描与点云管线作为技术底座呈现，而非产品名称本身。
🎯
RESEARCH GOALS
研究目标包括：验证「现实重构」管线（深度 / 平面 / 材质覆写）与虚拟世界 UI 的协同； 探索多控制模式下低延迟交互；构建可扩展的 Web 网关与实时链路； 为 AR/VR 与桌面同服同世界的体验设计提供参考。
CORE LOOP // 核心循环

进入世界 → 选择接入模式（桌面 / AR / VR）→ 选择位面主题与材质协议 → 扫描或加载房间模型 → 应用现实覆写 → 完成任务 / 收集资源 → 获得经验、货币、成就 → 解锁新皮肤、装备与位面方案 → 继续重构更高级场景。
